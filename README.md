# Halo

A native macOS assistant (SwiftUI/AppKit, Apple Silicon, macOS 26+). Mercy is the assistant and wake phrase.

```sh
cd HaloNative
bash scripts/build-app.sh
open build/Halo.app
```

See [HaloNative/README.md](HaloNative/README.md) for details and [ROADMAP.md](ROADMAP.md) for the plan.

The earlier Electron version of Mercy is no longer part of this repository; it remains in the git history before this change.
